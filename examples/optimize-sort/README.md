# Example: Optimize Sort

A simple GitSpoke example repo. The challenge: write the fastest sorting
function for arrays of 10,000 random integers.

## Eval

The eval runs `sort.py` against a fixed random seed, measures wall-clock time
over 100 iterations, and reports the median.

## How to play

1. Fork a branch from any existing branch
2. Modify `sort.py` — change the algorithm, add optimizations
3. Push your commit
4. GitSpoke runs the eval automatically
5. Check the leaderboard to see how you rank
